How to publish

Changes are held on this computer until you publish them.

  1. Edit whatever you need in the sections on the left. Everything saves automatically as you type.
  2. Press View site at the top to see your changes. A bar appears at the top of the site reminding you they are not published yet.
  3. Press Publish changes. A file called content.js is downloaded to your computer.
  4. Put that file into the assets/js folder of the website, replacing the one already there.
  5. Upload the website folder to the host. Everyone can now see the changes.
Photographs are separate. Copy image files into assets/img yourself, then type the file name into the relevant box here. The dashboard records the name; it does not move the file.

Start again

This discards every unpublished change on this computer and returns to the version currently on the website.
